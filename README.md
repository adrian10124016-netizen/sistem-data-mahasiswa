# Sistem Data Mahasiswa (CRUD & Autentikasi)

Sistem manajemen data mahasiswa berbasis web yang dilengkapi dengan fitur autentikasi user dan antarmuka modern bertema *Ocean Blue*.

## 🚀 Fitur Utama
- **Autentikasi User:** Login & Logout berbasis Session PHP dengan proteksi enkripsi password.
- **CRUD Data Mahasiswa:** Tambah, Lihat, Edit, dan Hapus data mahasiswa.
- **Tampilan Modern:** Desain antarmuka kustom menggunakan Google Fonts (Poppins) dan tema Ocean Blue.

## 🛠️ Teknologi yang Digunakan
- **Language:** PHP 8, HTML5, CSS3
- **Database:** MySQL / MariaDB
- **Server:** Apache (XAMPP)
- **Editor:** Visual Studio Code
